# DESIGN.md - FINLOG 디자인 시스템

## 프로젝트 정보
- **서비스명**: FINLOG (목표까지 남은 거리를 매일 보여주는 부부/개인 가계부)
- **버전**: 1.0.0 (PROD.MD v3.6 화면 개편 '하루 봉투' 기준)
- **최종 수정**: 2026-11-13
- **UI 프레임워크**: Next.js App Router + Tailwind CSS v4 + shadcn/ui (`src/components/ui`)
- **아이콘**: Lucide Icons (선 굵기는 테마 토큰 `--icon-stroke`)
- **토큰 원본**: `src/app/globals.css` — **이 문서는 설명이고, 값이 다르면 globals.css 가 맞다.** 토큰을 바꾸면 이 문서도 같이 고친다.

---

## 1. 원칙

1. **오늘 쓸 수 있는 돈이 먼저.** 홈 첫 줄은 하루 몫(대표 카드). 매일 여는 이유를 가장 크게 보여 준다.
2. **강조색은 한 곳에 몰아 쓴다.** 테마 강조색(`--brand`)은 대표 카드·목표 진척·버튼·선택 표시에만. 나머지는 바탕·먹색.
3. **빨강은 고쳐야 할 때만.** 초과·부족·닿지 않음에만 `--critical`. 단순 증감·주의는 `--warning` 또는 강조색.
4. **모은 돈은 가려 둔다.** 목표의 지금 모인 돈은 처음엔 가리고 눌러야 보인다(`HiddenMoney`, 기억하지 않음). 목표 금액·진척률은 보인다.
5. **색을 하드코딩하지 않는다.** 컴포넌트는 토큰(`bg-brand`, `var(--chart-1)` 등)만 쓴다. 테마마다 다른 값이 필요하면 `globals.css` 의 팔레트 블록에 토큰을 더한다.
6. **4가지 상태를 처음부터.** 로딩·빈 상태·오류·정상 + FINLOG 고유의 '초과' 상태.

## 2. 화면 테마(팔레트)

`<html data-palette="sunset|forest|sea|dusk">` × 밝게/어둡게(`.dark`). 사용자마다 `User.palette`(기본 `sunset`), 밝게/어둡게는 따로 고른다.

규칙(globals.css 주석과 같음): 각 팔레트의 밝게 블록은 모든 토큰을 정의하고, 어둡게 블록은 색과 그림자만 덮어쓴다. 블록 순서가 특이도에 영향을 주므로 순서를 바꾸지 않는다.

## 3. 타이포그래피

| 역할 | 토큰 | 노을 | 숲 | 바다 | 저녁 |
|---|---|---|---|---|---|
| 본문 | `--font-sans` | Gothic A1 | Gothic A1 | IBM Plex Sans KR | 고운돋움 |
| 제목 | `--font-heading` (h1·h2, 카드 제목) | = 본문 | = 본문 | = 본문 | 테마 지정 |
| 제목 굵기 | `--heading-weight` | 800 | 700 | 600 | 700 (고운돋움은 굵기 1종 — 합성 굵게 끔) |
| 숫자 | `--font-num` | FinNum + 본문 | 〃 | 〃 | 〃 |

- **숫자 서체 FinNum**: 설치된 고정폭 서체에서 숫자와 `, . % + −` 만 가져온다. `₩`·한글은 본문 서체로 남는다(₩가 W로 보이는 문제 방지).
- 금액·날짜·퍼센트처럼 줄을 맞춰야 하는 숫자는 **`.tabular` 클래스**(FinNum + `tabular-nums` + 자간 −0.02em). `Money` 컴포넌트가 기본으로 쓴다.
- 크기 단계(Tailwind): 대표 숫자 `text-4xl font-black` · 화면 제목 `text-xl md:text-2xl font-bold` · 카드 숫자 `text-xl~2xl font-bold` · 본문 `text-sm` · 보조 `text-xs` · 칸 라벨 `text-[11px]`.

## 4. 모양 · 간격

| 토큰 | 노을 | 숲 | 바다 | 저녁 | 쓰는 곳 |
|---|---|---|---|---|---|
| `--radius` | 0.875rem | 0.625rem | 0.75rem | 0.875rem | 카드·입력·버튼 (`--radius-sm`~`4xl`는 배수) |
| 대표 카드 모서리 | `--radius × 1.6` | 〃 | 〃 | 〃 | `[data-slot="card"][data-hero]` |
| `--progress-h` | 10px | 6px | 8px | 10px | 진척 막대 두께 |
| `--card-shadow` | 테두리 1px + 옅은 그림자 | 테두리 1px | 부드러운 그림자 2겹 | 보랏빛 그림자 2겹 | 카드 |
| `--card-spacing` | 기본 | 기본(촘촘) | 1.25rem | 1.5rem | 카드 안쪽 여백 |
| `--icon-stroke` | 2 | 2 | 1.75 | 1.5 | 아이콘 선 굵기 |

- 간격은 Tailwind 4px 단위(`gap-1`=4px … `gap-5`=20px). 형제 묶음은 `grid`/`flex` + `gap`, 낱개 margin 으로 맞추지 않는다.
- 레이아웃: 데스크톱 `md:grid-cols-[220px_1fr]`(사이드바), 본문 `max-w-6xl`, 휴대폰은 하단 탭 5개 + 본문 아래 여백 `pb-28`.

## 5. 컴포넌트 규칙

### 5.1 대표 카드 `data-hero`
테마가 가장 크게 드러나는 면. 카드 안에서 토큰을 다시 정의해 글자·막대·구분선·버튼이 채운 바탕을 따라온다.

| | 노을 | 숲 | 바다 | 저녁 |
|---|---|---|---|---|
| 바탕 | 주황 그라데이션 `#ff6a2b → #ec4a0c` | 먹색 `#1d211e` (강조 `#5fd39a`) | 청록 그라데이션 `#0b6e8a → #0a4560` | 보라 그라데이션 `#5b47c9 → #9a56b8` |

- 안쪽: `--foreground` 흰색, `--muted` 흰 20%, `--brand`·`--good` 흰색(숲은 민트), `--background` 흰 16%(테두리 버튼 바탕), `--input` 흰 32%.
- 쓰는 곳: 홈 쓸 수 있는 돈, 가계부 이번 달 요약, 목표 요약, 자산 요약, 위젯.

### 5.2 선택 버튼 묶음 `.seg` / `.seg-item[aria-checked]`
노을·바다 세그먼트형, 숲 밑줄형, 저녁 칩형. 보기 범위(우리/나/배우자)·거래 유형 등.

### 5.3 하단 탭 · 기록 버튼
- 탭 5개 고정: 홈 · 가계부 · 목표 · 자산 · 리포트 (PROD.MD AC-17). 설정은 헤더 프로필 메뉴.
- 선택 표시: 노을 아이콘 뒤 주황 알약, 숲 위쪽 막대, 바다 옅은 알약, 저녁 아래 점.
- 기록 버튼(`data-slot="fab"`): 휴대폰 오른쪽 아래 `+ 기록` 알약(`bg-primary`, 높이 48px), 탭바 위로 띄움. 데스크톱은 헤더 `기록하기` 버튼.

### 5.4 홈 대표 카드 — 이번 주 7칸 (`WeekStrip`)
- 일~토(가계부 달력과 같은 순서), 칸 크기 24px.
- 지난 날 아낌 = `bg-good` 채움 · 더 씀 = `ring-warning` 테두리 + 가운데 막대 · 오늘 = `ring-foreground` 테두리 · 다가올 날 = `bg-muted` · 지난달 = 30% 흐리게.
- 날마다 금액은 화면 읽기 프로그램용 텍스트(`sr-only`)로만.

### 5.5 목표 진척
- 홈 대표 목표: **진척 링**(`GoalRing`, 64px, `--muted` 바탕 위 `--brand` 호, 가운데 %).
- 목표 막대(`GoalProgressBar`): 높이 `--progress-h`, `--brand`. **'계획상 지금' 눈금** = `bg-foreground` 2px 세로선 + 아래 줄 "계획상 지금 N% · 지금 M%". 예전 방식 목표·다 모은 목표·0%면 그리지 않는다.

### 5.6 거래 행 카테고리 원 (`CategoryDot`)
- 32px, 모서리 10px, 흰 글자로 대분류 이름 첫 글자.
- 색: 대분류 이름 해시 → `--chart-1~5`(같은 분류는 늘 같은 색). 수입 = `--good`, 이체·저축·보정 등 = `bg-muted` + 유형 첫 글자.

### 5.7 가계부 격자 보기 (`MonthCalendar view="heat"`)
- `[격자 | 달력]` 전환, 달력 안에서 다시 `[월 | 주]`. 고른 보기는 `localStorage finlog.ledger.calendarView`.
- 칸 진하기 `data-heat` — 그달 가장 많이 쓴 날 대비 비율:

| 값 | 기준 | 바탕 |
|---|---|---|
| `0` | 지출 없음 | `--muted` |
| `1` | ≤ 25% | `--brand` 22% + `--card` |
| `2` | ≤ 60% | `--brand` 48% + `--card` |
| `3` | > 60% | `--brand` (흰 글자) |
| `future` | 오늘 뒤 | 투명 + `--border` 1px |

### 5.8 가린 금액 (`HiddenMoney`)
`●●●●●●` + 눈 아이콘 → 누르면 금액. 링크 카드 안에 넣을 때는 카드 링크를 제목의 `::after` 로 덮고 버튼만 `relative z-10` 으로 올린다(버튼을 링크 안에 넣지 않는다).

## 7. 접근성

- 진척 막대·링은 `role="progressbar"`/`role="img"` + `aria-label`(이름과 %).
- 토글 버튼은 `aria-pressed`, 선택 묶음은 `role="group"` + `aria-label`.
- 색만으로 구분하지 않는다: 주간 7칸 '더 씀'은 테두리 + 막대 모양, 격자는 날짜 숫자와 `aria-label`(지출 금액).
- 포커스: `focus-visible:ring-[3px] ring-ring/50`. 숨기지 않는다.
